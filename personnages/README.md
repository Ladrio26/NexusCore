# Images des personnages

Les images de ce dossier s’affichent **automatiquement** dans l’app (Team Builder, Collection, Bestiaire, combat, etc.) selon le **nom** de l’unité.

## Convention de nommage

Le fichier doit porter le nom du **premier mot** du nom d’unité, en **PNG**, première lettre en majuscule.

| Nom de l’unité (en base) | Fichier à déposer |
|--------------------------|-------------------|
| `Dolo, L'Épine Absolue`  | `Dolo.png` |
| `Francky, L'Ancien Primordial` | `Francky.png` |
| `Alpha` | `Alpha.png` |

- On prend le **premier mot** (avant espace ou virgule).
- Nom du fichier : ce mot avec première lettre en majuscule + `.png`.

Format : **PNG** uniquement.

Après avoir ajouté un fichier ici (ex. `NouveauPerso.png` pour une unité dont le nom commence par « NouveauPerso »), l’image s’affiche automatiquement partout où l’unité est affichée.
